🎓 중국어 말하기 평가 & 구글 시트 연동

* 기본값: 개발 교사 원본 시트 자동 연결. 다른 교사는 [📋 원본 시트 복사하기]를 눌러 사본을 만든 후 해당 시트 링크를 입력하세요.

📖 구글 시트 복사 및 사용 안내

  1. 1. 원본 시트 복사: 상단 [📋 원본 시트 복사하기]를 클릭하면 원본 시트 사본 만들기 창이 열립니다. [사본 만들기]를 누르세요.
  2. 2. 시트 공유 권한: 복사된 시트 우측 상단 [공유] 클릭 후 '링크가 있는 모든 사용자'를 '편집자'로 변경하세요.
  3. 3. 내 시트 주소 붙여넣기: 복사한 시트의 링크를 위 [연결된 구글 시트] 칸에 넣으면, 그 시트에 학급별 탭(예: 2학년 2반)이 자동 생성됩니다.
  4. 4. 4자리 학번 자동 변환: 학생이 2022를 입력해도 자동으로 20202(2학년 02반 02번)로 환산되어 저장됩니다.
