📖 학생 주도 다국어 연습기 기능 안내

  1. 기본 문장 보존: [기본] 수험생 응원 문구는 영구 보존되며, 선생님이 만든 세트는 최근 10개까지 드롭다운에 누적 보관됩니다.
  2. 스마트 번역/직접 입력: 한자를 직접 넣으면 번역기 왜곡 없이 그대로 들어가며, 한국어를 넣으면 해당 언어로 완벽 번역됩니다.
  3. QR코드 배포: [📱 학생 배포용 QR] 버튼을 누르면 현재 설정된 문항 세트가 담긴 주소로 QR코드가 즉시 생성됩니다.
  4. 단어 카드 소리 듣기: 결과 피드백 창의 단어 배지를 클릭하면 해당 단어의 원어민 발음(TTS)이 재생됩니다.
